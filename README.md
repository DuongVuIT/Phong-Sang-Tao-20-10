# 🌹 20/10 · Phòng Sáng Tạo

Món quà nhỏ nhân Ngày Phụ nữ Việt Nam 20/10.

👉 https://duongvuit.github.io/Phong-Sang-Tao-20-10/

![preview](public/og-image.png)

## Công nghệ

- **Blender** (`bpy`) – dựng mô hình 3D bằng code: `blender/build_scene.py`
- **Remotion** – video lời chúc (phát trên web + xuất MP4)
- **React Three Fiber** – cảnh 3D trên web
- **GitHub Actions → GitHub Pages** – tự build & deploy khi push `main`

## Chạy ở máy

```bash
npm install
npm run dev        # web
npm run studio     # Remotion Studio
npm run blender    # dựng lại mô hình 3D (cần Python 3.11 + pip install -r blender/requirements.txt)
```

Nội dung quà được mã hoá trong `public/sealed/` – chỉ người có link riêng mới mở được.
